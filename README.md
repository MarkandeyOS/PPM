# Markandey Pandey Pustak Mandir

Public website for the Gorakhpur bookstore, with books, stationery, uniforms, sports supplies, and school website samples.

## Main pages

- `index.html` — bookstore homepage and links to the main sections.
- `store.html` — book catalogue and school set enquiry builder.
- `stationery.html`, `uniforms.html`, and `sports.html` — product sections.
- `website-samples.html` — gallery of 60 fictional school website concepts.
- `demo.html` — featured Aarohan Public School sample.
- `school-11.html` through `school-69.html` — the remaining individual concept pages.
- `privacy.html` and `terms.html` — site policies.

## File layout and naming

The site is a static GitHub Pages website. Keep `index.html` in the repository root and preserve the `assets/` directory structure. Shared styles, scripts, images, data, and publisher catalogues are stored under `assets/`.

Use lowercase kebab-case for new filenames, such as `new-page.html` or `new-image.webp`. Keep the existing numbered `school-*.html` names stable because the gallery, sitemap, and search engines link to them. When renaming an existing file, update every link or reference in HTML, CSS, JavaScript, and `sitemap.xml` in the same change.

## School concept samples

The concepts are fictional design samples. School names, locations, notices, statistics, portraits, and school photographs are illustrative; replace them with school-approved information and images before presenting a concept as a real school's website.

## Publisher catalogues

PDF catalogues are in `assets/catalogs/`. The book-set enquiry builder uses catalogue information as a guide; confirm the edition, availability, and final prices with the publisher or shop before ordering.
